## Gmail en Render: usa Google Apps Script (HTTPS)
Para probar el remitente Gmail antes de publicar, ejecuta `PROBAR_CORREO_WINDOWS.bat` y elige **opción 2**.
Requiere la URL `/exec` de Apps Script y el secreto de Script Properties. El secreto se introduce oculto y no queda guardado.
Para instalar el servicio, sigue `CONFIGURAR_RENDER_GMAIL_APPS_SCRIPT.md`. Gmail SMTP (opción 1) es sólo para PC; no sirve para Render gratuito.
